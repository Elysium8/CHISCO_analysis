This repository contains: - EEG-to-text embedding models - CHISCO baseline implementation - Sentence-aligned train/validation/test splitting - Global retrieval evaluation - K-AFC evaluation - Semantic hypothesis testing - Grad-CAM interpretability analysis - Data scaling and augmentation studies - Multi-seed experiment aggregation --- # Overview The goal of this project is to map EEG recordings directly into a shared semantic embedding space, enabling retrieval of natural language sentences from brain activity. The repository supports two paradigms: - **Read**: participants read presented sentences. - **Imagine**: participants internally recalled and imagined previously presented sentences. The primary model consists of: 1. EEG feature extraction front-end 2. Brain module incorporating: - Spatial attention - Subject adaptation - Residual dilated temporal convolutions 3. Projection into sentence embedding space A reproduction of the original CHISCO architecture is also provided as a baseline. --- # Installation Create a Python environment and install dependencies: ```bash pip install -r requirements.txt ``` Key dependencies include: - PyTorch - Transformers - NumPy - SciPy - scikit-learn - Matplotlib - Pandas - HuggingFace Transformers --- # Dataset The repository assumes access to the CHISCO dataset: ``` ds005170/ ``` Sentence embeddings should be stored as: ``` sentence_bert_embs.json ``` mapping: ```json { "sentence text": [embedding values] } ``` --- # Training The primary training entrypoint is: ```bash python train_script_with_split.py ``` Example: ```bash python train_script_with_split.py \ --task read \ --seed 4 \ --split-file splits/train_val_test_split.json ``` Supported tasks: ```bash --task read --task imagine ``` --- # Sentence-Aligned Train / Validation / Test Splits Experiments use a fixed sentence-aligned split: ```text Train: 80% Validation: 10% Test: 10% ``` The same sentence assignment is used across both read and imagine paradigms, ensuring direct comparability between tasks. Each experiment stores: ```text split.json ``` containing: ```json { "train_sentences": [...], "val_sentences": [...], "test_sentences": [...] } ``` allowing exact reconstruction of evaluation datasets. --- # Experiment Logging Training automatically creates experiment folders: ```text experiments/ └── read/ └── 2026-04-28_16-23-51__split=sentence_aligned_read_imagine__seed=4/ ``` Each run contains: ```text config.json split.json metrics.jsonl best_checkpoint.pt last_checkpoint.pt ``` --- # Architectures ## Full Model The default architecture combines: - EEGNet-style front-end - Spatial attention - Subject adaptation layer - Residual dilated temporal convolutions - Projection head Model components are implemented in: ```text model_parts.py Brain_Module.py ``` ## CHISCO Baseline A reproduction of the original CHISCO architecture is available: ```bash --arch chisco_baseline ``` using: ```text CHISCO_baseline_model.py ``` --- # Global Retrieval Evaluation Evaluate retrieval against the entire sentence corpus: ```bash python eval_global_retrieval.py \ --exp-dir <experiment_folder> ``` Outputs: ```text global_retrieval.json ``` containing: ```json { "top1": ..., "top5": ..., "top10": ..., "top50": ... } ``` Evaluation is performed on the held-out test set reconstructed from the experiment split file. --- # K-AFC Evaluation Evaluate K-way forced-choice retrieval: ```bash python k_afc_evaluation.py \ --exp-dir <experiment_folder> ``` Outputs: ```text k_afc_results.json k_afc_curve_top5.png k_afc_curve_top10.png k_afc_curve_top50.png ``` and corresponding relative-accuracy curves. To aggregate across multiple runs: ```bash python k_afc_evaluation_multi.py \ --exp-root <folder> ``` --- # Random Noise Baseline Evaluate retrieval performance under random EEG input: ```bash python test_random_noise.py \ --exp-root <folder> ``` This establishes empirical chance-level retrieval performance under identical evaluation conditions. --- # Semantic Analysis Semantic category preservation is evaluated using: ```bash python semantic_hypothesis_testing.py ``` The script tests whether retrieved sentences belong to the same semantic category more frequently than expected under chance. --- # Interpretability Grad-CAM analysis: ```bash python GRADCAM.py \ --exp-root <folder> ``` Generates: - Temporal saliency maps - Channel importance maps - Topographic scalp visualisations - Spatiotemporal attribution analyses for both read and imagine paradigms. --- # Subject Variance Analysis To investigate subject-specific structure: ```bash python subject_variance.py ``` This computes covariance-based representations and compares inter-subject geometry using PCA and log-Euclidean correlation embeddings. --- # Data Scaling Experiments Train using fractions of the training set: ```bash --train-data-fraction 0.1 ``` through ```bash --train-data-fraction 1.0 ``` Results can be visualised using: ```bash python plot_data_scaling.py ``` --- # Data Augmentation Ablations Supported augmentations: ### Gaussian Noise ```bash --noise-std ``` ### Temporal Jitter ```bash --jitter-max ``` ### Channel Dropout ```bash --channel-dropout-p ``` Complete augmentation can be disabled using: ```bash --no-augment-train ``` Multi-seed augmentation studies can be summarized using: ```bash python summarize_augmentation_results.py ``` which reports mean retrieval performance and 95% confidence intervals. --- # Reproducibility All experiments record: - configuration - split assignment - random seed - checkpoints - metrics inside the experiment folder. Recommended seeds: ```text 4 6 8 10 12 ``` for reporting mean performance and 95% confidence intervals. --- # Citation If you use this repository, please cite: ```bibtex @article{zhang2024chisco, title={CHISCO: Open-Vocabulary EEG-to-Text Decoding}, author={Zhang et al.}, year={2024} } ``` ::: One thing I'd probably add if this is going public is a short **"Results"** section near the top with your current Read/Recall Top-5/10/50 numbers and links to the main figures.
